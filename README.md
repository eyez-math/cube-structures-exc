# מבנים מקוביות — גרסה מתוקנת

אתר סטטי המתאים ל-GitHub Pages.

## קבצים
- `index.html` — שלד האתר.
- `styles.css`, `modules.css` — עיצוב.
- `app.js` — מנוע הפעילויות, חישוב מבטים, שמירה ובדיקת תשובות.
- `data/exercises.js` — נתוני התרגילים.

## תיקונים בגרסה זו
- תרגיל 2 הותאם מחדש לעמוד 4 של החוברת.
- סעיף ג׳ משתמש במבט מלפנים (ולא מבט מימין).
- סעיף ו׳ קיבל תרשים מלמעלה בגודל 4×2, כפי שמופיע בחוברת.
- שלוש אפשרויות סעיף ו׳ נבנו מחדש כך שהאפשרות הנכונה מתאימה לכל שלושת המבטים.
- סדר כרטיסי המבטים נקבע מפורשות לכל סעיף כדי לשמור על סדר החוברת.
- נוספה בדיקה שמונעת "בדיקת תשובה" בלי בחירת מבנה.
- נשמר מצב תלמיד ב-localStorage עם גרסה חדשה כדי שלא ייטענו תשובות ישנות לתוכן שתוקן.
- נוספה הגנה מפני מצב שמור ישן/פגום או שינוי במספר השאלות.

## פרסום
העלה את תוכן התיקייה לשורש ה-repository והפעל GitHub Pages על branch `main`, folder `/ (root)`.


## תוספת בגרסה זו

- בכל סעיף יש גם שדה נפרד למספר הקוביות במבנה.
