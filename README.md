# חוברת מבנים מקוביות

האתר סטטי ומתאים ל-GitHub Pages. תיקיית `dist` מכילה את האתר המוכן לפרסום.

## מבנה הקבצים

- `dist/index.html` - שלד האתר. בדרך כלל אין צורך לשנות אותו.
- `dist/styles.css` ו-`dist/modules.css` - העיצוב.
- `dist/app.js` - מנוע הפעילויות, הניווט והבדיקה.
- `dist/data/exercises.js` - תוכן התרגילים, המבנים והתשובות.

## הוספת תרגיל קיים מאותו סוג

עורכים רק את `dist/data/exercises.js` ומוסיפים אובייקט חדש למערך
`window.CUBE_EXERCISES`.

סוגי הפעילויות הנתמכים כרגע:

- `structure-to-views` - מוצג מבנה והתלמיד יוצר תרשים מספרים וארבעה מבטים.
- `match-structure` - מוצגים מבטים והתלמיד בוחר את המבנה המתאים.
- `numbers-to-views` - מוצג תרשים מספרים והתלמיד יוצר ארבעה מבטים.

אם מוסיפים שאלות לאחד משלושת הסוגים האלה, אין צורך לשנות את `index.html`,
את העיצוב או את מנוע האתר.

## פרסום ב-GitHub Pages

בהעלאה הראשונה מעתיקים את תוכן תיקיית `dist` לשורש מאגר GitHub ומפעילים
GitHub Pages מתוך הענף `main` והתיקייה `/ (root)`.

בעדכונים הבאים Git מעלה רק את הקבצים שהשתנו. בדרך כלל, בהוספת תרגיל נוסף,
רק `data/exercises.js` ישתנה.

## בדיקת תשובות

לאחר שינוי מבנים או תשובות מריצים משורש הפרויקט:

```bash
node tests/answers.test.js
```

הבדיקה משווה את פרופילי המבטים ואת מפתח ההתאמה לפתרונות שבחוברת, כולל
הכיוון הנכון של מבט משמאל ומבט מימין ביחס לחץ החזית.
